# Third-party scanner model

`dinov2_vits14_224.onnx` is the DINOv2 ViT-S/14 backbone exported by
`sefaburak/dinov2-small-onnx`.

- Source: <https://huggingface.co/sefaburak/dinov2-small-onnx>
- Upstream: <https://github.com/facebookresearch/dinov2>
- License: Apache License 2.0
- SHA-256: `4df36ef0716a8f17d984fc7546a3a5d670fda6911eb298592250cb9e26756063`

The searchable embedding index is built with `python build_embeddings.py` from
the public metadata and image URLs in
<https://github.com/PokemonTCG/pokemon-tcg-data>. Reference card images are
downloaded only during the build and are not redistributed in this repository.
